
## Branch Admin Dashboard — LMS

### 1. Overview / Summary Cards
- Total enrolled students in the branch
- Active courses in the branch
- Total instructors/teachers assigned
- Pending approvals (enrollments, leave requests, etc.)
- Revenue / Fee collection summary (if applicable)
- Upcoming batch schedules

---

### 2. Student Management
- View all students enrolled under this branch
- Add / Edit / Deactivate students
- Assign students to courses or batches
- View student progress & performance reports
- Manage student attendance
- Handle fee payment status per student

---

### 3. Instructor / Teacher Management
- View all instructors assigned to the branch
- Add / Edit / Remove instructors
- Assign instructors to specific courses or batches
- View instructor schedules and workload
- Track instructor performance/ratings

---

### 4. Course & Batch Management
- View all courses offered at the branch
- Create / Edit / Delete batches under a course
- Set batch timings, capacity, and start/end dates
- Assign instructors to batches
- Monitor course completion rates

---

### 5. Attendance Management
- Mark / View attendance for each batch
- Generate attendance reports (student-wise, batch-wise)
- Set attendance thresholds / alerts

---

### 6. Fee & Payment Management
- View fee structure for each course/batch
- Track student payment status (paid, pending, overdue)
- Generate fee receipts
- View branch-level revenue reports
- Apply discounts or scholarships

---

### 7. Schedule / Timetable
- View and manage class schedules for the branch
- Handle rescheduling or cancellations
- Holiday / leave calendar management

---

### 8. Announcements & Communication
- Post announcements for students/instructors in the branch
- Send notifications (email/SMS/in-app)
- Manage notice board

---

### 9. Reports & Analytics
- Student enrollment trends
- Course-wise performance reports
- Attendance summary reports
- Fee collection reports
- Batch completion status

---

### 10. Settings (Branch-level)
- Branch profile (name, address, contact)
- Working hours / holidays
- Notification preferences
- User roles & permissions within the branch

---
